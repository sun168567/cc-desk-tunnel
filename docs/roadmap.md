# 路线与现状

## 已完成

- 两端消息契约、离线模拟服务与界面，用于不依赖账号的开发和回归。
- 反向执行通道：WSS 登录、临时密钥、经服务地址建立的 WSS 执行通道、就绪探测、断开回收；Windows 无常驻服务、命令无弹窗。
- 原生集成：经官方 Agent SDK 驱动未修改的 Claude Code，审批转接、运行中追加输入、会话持久化与恢复、改名、删除、分叉、主动压缩。
- 界面：三栏布局与分类设置页、项目与会话管理（置顶、更换项目、导出）、流式过程展示、提问卡片、模型 / 推理强度 / 审批模式 / 上下文、Claude Code 设置页、内嵌原生终端、账号登录与额度、调用统计、定时任务、草稿保存、系统通知、可改的快捷键、托盘后台。
- 发行与部署：Windows 安装包（自带运行组件）、Docker / Compose 部署脚本、三种 TLS 入口、备份恢复、原地升级、跟踪发布页、从客户端一键升级服务端与客户端。

各版本的变化见[变更记录](../CHANGELOG.md)。

## 已实现、尚未在真实部署中验证

- CLI 2.1.293 的 Haiku 5.5 调用与 Linux 长任务：只验证了隔离环境下的初始化和状态接口。
- 周额度统计和会话活动时间的恢复：测试通过，尚未在生产库应用。
- 后台任务：用 CLI 2.1.293 实测过“回答结束时任务仍在、任务完成后自动开始下一轮”；经服务端与界面的完整流程、结束单个任务、长时间不退出的任务尚未在真实部署中验证。等待后台任务的会话仍会挡住刷新模型列表、原生终端等需要没有运行的操作。
- 域账号的 SSH 允许名单：按用户报告的 sshd 日志修改，没有域环境可测。
- 分叉出的会话在真实 CLI 中续聊。
- Claude 经 SSH 修改 `schedules.json` 后定时任务生效；客户端长时间驻留后台时任务的准点情况。
- 服务端升级时安装新版本所需的依赖、启动失败时退回镜像版本；版本不一致的客户端在登录页升级。
- 登录限速在 nginx 反代模式下按真实来源地址区分（依赖 `X-Real-IP`）。
- 思考摘要在各模型上的显示。
- Max 订阅下按模型的每周额度（Fable）在账号页的显示：按官方接口的字段实现，尚未用 Max 账号核对。
- Claude 的提问：自动审批模式下是否同样到达界面，选择的答案是否被原生采纳。
- 更换会话项目、重连后 PowerShell 路径变化：Claude 看到随消息给出的说明后是否改用新值；一轮中途自动压缩的情形。
- 重连后提示缓存的命中：原因与修复已由请求记录和单元测试确认，修复部署后的实际命中率尚未观察。
- 设置页新增的 8 个 Claude Code 设置项在经 SDK 的无界面运行中是否逐项生效。
- 连接失败的提示：杀毒软件真实拦截 sshd、执行通道建立不了、各类证书与反代错误时给出的文字，只有单元测试和本机演练。
- WSS 执行通道：本机用真实的 OpenSSH 走通了并发命令、大输出、scp、通道中断与恢复；尚未在真实网络、nginx 反代和丢包、高时延下验证。
- Windows 通知点击后回到会话、提示音开关；标题栏拖动与系统窗口按钮的贴合。
- 经系统代理连接：已用本机的测试代理验证控制连接发出 CONNECT，执行通道与它走同一条路径，尚未在常见代理软件和真实服务端之间完整走通。

## 计划

| 事项 | 说明 |
| --- | --- |
| Linux 客户端与多设备 | Linux 图形客户端与终端客户端（实验性）；同一使用者可以同时连接自己的多台设备。取舍见[评估记录](research/linux-client-and-tunnel.md) |
| 断线宽限与重连接管 | 网络短暂中断后不结束运行，重连的客户端接回原运行 |
| 终端与图形会话打通 | 目前内嵌终端是独立的原生会话 |
| 富内容 | SVG 显示、图片与附件的会话临时传输 |
| 发行质量 | 安装包代码签名；Windows on ARM、Linux arm64；IPv6 地址 |
| 运维 | 证书自动续期；长任务与高负载下的容量评估 |
| 重置卡 | 官方 CLI 可用 `/limit-reset`，是否提供取决于账号；SDK 没有读取张数或使用重置卡的接口，图形入口暂缓。内嵌的原生终端运行的是交互式 CLI，可在那里试用该命令（未验证） |

## 明确不做

- 多用户、租户隔离、把订阅包装成共享 API。
- 修改或包装 Claude Code 本体，伪造运行环境特征。
- 自建第二套审批模型、上下文管理或远程执行协议。
