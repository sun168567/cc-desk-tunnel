# 路线与现状

## 已完成

- 两端消息契约、离线模拟服务与界面，用于不依赖账号的开发和回归。
- 反向执行通道：WSS 登录、临时密钥、frp 回环映射、就绪探测、断开回收；Windows 无常驻服务、命令无弹窗。
- 原生集成：经官方 Agent SDK 驱动未修改的 Claude Code，审批转接、运行中追加输入、会话持久化与恢复、改名、删除、分叉、主动压缩。
- 界面：项目与会话管理、流式过程展示、模型 / 推理强度 / 审批模式 / 上下文、Claude Code 设置页、内嵌原生终端、账号登录与额度、调用统计、定时任务、草稿保存、托盘后台。
- 发行与部署：Windows 安装包（自带运行组件）、Docker / Compose 部署脚本、三种 TLS 入口、备份恢复、原地升级、跟踪发布页、从客户端一键升级服务端与客户端。

各版本的变化见[变更记录](../CHANGELOG.md)。

## 已实现、尚未在真实部署中验证

- 分叉出的会话在真实 CLI 中续聊。
- Claude 经 SSH 修改 `schedules.json` 后定时任务生效；客户端长时间驻留后台时任务的准点情况。
- 客户端静默自升级的完整链路。
- 服务端跟踪发布页并从客户端一键升级（下载、校验、安装依赖、重启、启动失败时退回镜像版本）；版本不一致的客户端在登录页升级。
- 登录限速在 nginx 反代模式下按真实来源地址区分（依赖 `X-Real-IP`）。
- 思考摘要在各模型上的显示。

## 计划

| 事项 | 说明 |
| --- | --- |
| 断线宽限与重连接管 | 网络短暂中断后不结束运行，重连的客户端接回原运行 |
| 终端与图形会话打通 | 目前内嵌终端是独立的原生会话 |
| 富内容 | SVG 显示、图片与附件的会话临时传输 |
| 发行质量 | 安装包代码签名；Windows on ARM、Linux arm64；IPv6 地址 |
| 运维 | 证书自动续期；长任务与高负载下的容量评估 |

## 明确不做

- 多用户、租户隔离、把订阅包装成共享 API。
- 修改或包装 Claude Code 本体，伪造运行环境特征。
- 自建第二套审批模型、上下文管理或远程执行协议。
